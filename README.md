# Learning Platform

Учебная платформа «учитель ↔ ученик» для домашних заданий с математикой.

## Возможности

**Учитель**
- Создаёт домашние задания (название, описание, дедлайн) с задачами; в условиях задач поддерживается LaTeX (`$...$`, `$$...$$`).
- Для каждой задачи можно указать эталонный ответ (для автопроверки) и требование приложить фото решения.
- Привязка учеников по уникальному 6-символьному коду учителя.
- Просмотр ДЗ со всеми решениями учеников, просмотр ответов каждого ученика, выставление оценки и комментария.

**Ученик**
- Вкладка «Домашние задания»: карточки всех ДЗ учителя с фильтрами (Все / Активные / Завершённые), статусом решения и подсветкой близких/просроченных дедлайнов.
- Решение ДЗ с **автосохранением** каждого ответа в БД (debounce 1.5 с, индикатор «Сохранение…/Сохранено», повтор при ошибке сети).
- Загрузка фото-ответов (PNG/JPEG/WEBP/GIF до 4 МБ, хранятся локально в `public/uploads/`).
- Отправка ДЗ → **автопроверка** текстовых ответов (нормализация: trim, lowercase, пробелы вокруг операторов, числовое сравнение) с результатом «Правильных ответов: X из Y».
- После отправки форма — только чтение; видна оценка и комментарий учителя после проверки.

## Стек

- [Next.js 14](https://nextjs.org) (App Router, Server Components + Server Actions)
- TypeScript (strict)
- Tailwind CSS + CSS-переменные тем (light/dark через `next-themes`)
- Prisma ORM + SQLite
- Auth: подписанный JWT (`jose`) в httpOnly-cookie, пароли — `bcryptjs`
- Валидация — Zod; рендер формул — KaTeX; UI-иконки — lucide-react

## Запуск

Требуется Node.js ≥ 18.

```bash
npm install
cp .env.example .env          # задайте JWT_SECRET (openssl rand -base64 32)
npx prisma db push            # создаёт dev.db (DATABASE_URL=file:./dev.db)
npx prisma db seed            # демо-данные (учитель + ученик + ДЗ с LaTeX)
npm run dev                   # http://localhost:3000
```

Скрипты: `npm run build`, `npm start`, `npm run lint`, `npm run db:studio`.

## Тестовые учётные данные (из `prisma/seed.ts`)

| Роль     | E-mail               | Пароль       | Примечание                    |
|----------|----------------------|--------------|-------------------------------|
| Учитель  | `teacher@example.com`| `teacher123` | код привязки: **ABC123**      |
| Ученик   | `student@example.com`| `student123` | уже привязан к учителю        |

Сид также создаёт демо-ДЗ «Алгебра: квадратные уравнения» с задачами (в т.ч. с эталонными ответами для автопроверки и задачей с обязательным фото).

## Как пользоваться

1. Войдите как учитель → создайте ДЗ с задачами (LaTeX в условии: `$x^2 - 5x + 6 = 0$`).
2. Выйдите, войдите как ученик → «Домашние задания» → откройте ДЗ, решайте (ответы сохраняются автоматически).
3. Нажмите «Отправить ДЗ» → увидите результат автопроверки.
4. Войдите как учитель → откройте ДЗ → кликните на ученика → проверьте ответы, выставьте оценку и комментарий.

## Примечания

- Фото-ответы сохраняются локально в `public/uploads/` (без S3 — упрощение для демо).
- Дедлайн менее 24 часов или просроченный подсвечивается красным.
- Без привязанного учителя ученик видит баннер со ссылкой на `/student/link-teacher`.
